I couldn’t find much online about sending multiple values from Unreal Engine to Arduino, so I wanted to share a method that worked for me. The code is adapted from the TouchDesigner documentation: https://docs.derivative.ca/Arduino.

I’m currently using it with two servos, but it can be extended to control multiple components. Just update the code accordingly.
